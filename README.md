# ҚМЖ Генератор

Мұғалімдерге арналған, жасанды интеллект (Google Gemini) көмегімен **Қысқа мерзімді жоспар (ҚМЖ)** мазмұнын толық сценарий деңгейінде дайындап беретін веб-қосымша. Пән, сынып және тақырыпты енгізу жеткілікті — қалғанын AI толтырады: мұғалімнің нақты сөйлейтін сценарийі, деңгейлік тапсырмалар, дайын баллдық кесте және басып шығаруға дайын тапсырма карточкалары.

## Негізгі мүмкіндіктер

- **Толық сценарий мазмұны** — әр кезеңде мұғалімнің нақты айтатын сөздері, оқушы әрекеті, деңгейлік (Базалық/Негізгі/Жетілдірілген) тапсырмалар, топ ішіндегі рөлдер
- **Ресми үлгіге сай үш деңгейлі сабақ мақсаты** — «Барлық/Көпшілік/Кейбір оқушылар үшін» құрылымы (ҚМЖ бұйрығына сай)
- **Қатысқандар/Қатыспағандар саны** — соңғысы әрқашан бос қалады, сабақ күні қолмен толтырылады (нақты тәжірибеге сай)
- **Сурет орны (плейсхолдер)** — AI сурет сала алмайды, бірақ тапсырма үшін сурет қажет болса, не салу керегін сипаттап, бос орын қалдырады (сайтта да, Word/PDF-те де)
- **Жұмыс түрін таңдау** — жеке/жұптық/топтық/жоба/зертханалық/практикалық (3-ке дейін); жеке/жұптық жұмыста тапсырмалар бірінен соң бірі нөмірленеді, топтық жұмыста деңгей бойынша бөлінеді
- **ЕБҚ режимі** — әр кезеңге ерекше білім беру қажеттілігі бар оқушыларға арналған бейімдеу бағаны қосылады
- **БЖБ режимі** — рефлексия орнына толық қалыптастырушы бағалау тапсырмасы генерацияланады
- **Дәл есептелген баллдық кесте** — жалпы балл қосындысы AI-ден емес, кодтан (тапсырма баллдарынан) есептеледі, қате қосынды болмайды
- **Дайын тапсырма карточкалары** — сыныпта тікелей басып беруге дайын нұсқа
- **Ашық/қараңғы тема** — таңдау браузерде сақталады
- **Қолданушы келісімі мен Құпиялылық саясаты** беттері (`/terms`, `/privacy`)
- Нәтиже сайтта толық өңделеді, **Word (.docx)** немесе **PDF** түрінде жүктеп алынады

## Технологиялар

- **Frontend:** Vite + React + TypeScript + React Router (`/client`)
- **Backend:** Node.js + Express (`/server`) — Gemini API-ге сұраныс жасайтын қауіпсіз прокси
- **AI:** Google Gemini API (`gemini-2.5-flash`, structured JSON output)
- **Экспорт:** `docx` кітапханасы (Word), `jsPDF` + `jspdf-autotable` (PDF) — екеуі де деректен (`plan` объектісінен) тікелей құрастырылады, сондықтан нәтиже құрылғы/терезе өлшеміне тәуелсіз әрдайым бірдей әрі ретті болады
- **Иконкалар:** `lucide-react`

## Локалды іске қосу

### 1. Тәуелділіктерді орнату

```bash
npm run install:all
```

### 2. Gemini API кілтін алу

1. https://aistudio.google.com/app/apikey сайтына кіріп, тегін API кілт жасаңыз.
2. `server/.env.example` файлын `server/.env` етіп көшіріп, кілтті қойыңыз:

```bash
cp server/.env.example server/.env
```

```
GEMINI_API_KEY=сіздің_кілтіңіз
GEMINI_MODEL=gemini-2.5-flash
PORT=5000
```

> **Ескерту:** Gemini модельдерінің атаулары мен тегін квоталары уақыт өте өзгеруі мүмкін. Ағымдағы тізімді https://ai.google.dev/gemini-api/docs/models бетінен тексеріп отырыңыз және қажет болса `GEMINI_MODEL` мәнін ауыстырыңыз.

### 3. Дамыту режимінде іске қосу

Екі терминалда бөлек:

```bash
npm run dev:server   # http://localhost:5000
npm run dev:client   # http://localhost:5173 (Vite dev server, /api сұраныстарын 5000-ға проксилейді)
```

Браузерде `http://localhost:5173` ашыңыз.

## Production build

```bash
npm run build   # client/dist қалыптастырады
npm start       # Express сервері client/dist-ті + /api маршруттарын бір порттан береді
```

## Hostinger-ге деплой

Сіздің Node.js hosting жоспарыңызда (мысалы, `qmzh.seriktesbol.com` субдоменіне):

1. Барлық жоба файлдарын (`node_modules` мен `.env`-тен басқа) серверге жүктеңіз.
2. Hostinger hPanel → **Node.js** бөлімінде:
   - **Application root:** жоба орналасқан папка
   - **Application startup file:** `server/index.js`
   - **Node.js version:** 18 немесе жоғары
3. **Environment variables** бөлімінде қосыңыз:
   - `GEMINI_API_KEY`
   - `GEMINI_MODEL` (міндетті емес, әдепкі: `gemini-2.5-flash`)
   - `PORT` (Hostinger өзі береді, әдетте қолмен қоюдың қажеті жоқ)
4. SSH терминал арқылы (немесе Hostinger-дің "Run NPM install" батырмасы):

```bash
npm run install:all
npm run build
```

5. Қосымшаны **Restart** етіңіз. Express сервері `client/dist` ішіндегі дайын frontend-ті және `/api/generate` маршрутын бір порттан береді, сондықтан frontend үшін бөлек статикалық хостинг қажет емес.

## Қауіпсіздік және шектеулер

- Gemini API кілті тек backend-те сақталады, frontend-ке ешқашан жіберілмейді.
- `/api/generate` маршруты 15 минутта 20 сұраныспен шектелген (`express-rate-limit`) — тегін Gemini квотасын үнемдеу үшін. Қажет болса `server/index.js` ішіндегі `generateLimiter` мәндерін өзгертіңіз.
- Барлық енгізу өрістері серверде валидацияланады (бос өріс, максимал ұзындық, сабақ ұзақтығының ауқымы).

## Мазмұнды кеңейту

- **Форма өрістерін өзгерту:** `client/src/components/LessonForm.tsx` және `client/src/types.ts`.
- **AI промптын түзету** (мысалы, басқа әдіснамалық стандартқа сай): `server/gemini.js` ішіндегі `buildPrompt` функциясы.
- **Жауап схемасын түзету** (жаңа өріс қосу/алу): `server/gemini.js` ішіндегі `buildResponseSchema`/`stageSchema` — бұл ЕБҚ/БЖБ режимдеріне қарай динамикалық құрылады.
- **Баллдық қорытынды логикасы:** `client/src/utils/scoring.ts` — тапсырма баллдарынан жалпы қосындыны есептейді, AI-ден тікелей сұралмайды (қате қосынды тәуекелін болдырмау үшін).
- **PDF-тегі қаріп:** `client/src/utils/pdfFonts.ts` — Noto Serif қарпінің Latin+Cyrillic (қазақша әріптерді қоса) диапазонына дейін сығылған base64 TTF нұсқасы. Егер басқа қаріп керек болса, `fonttools` арқылы жаңа TTF-ті сол сияқты base64-ке айналдырып ауыстыруға болады.
- **ҚМЖ бөлімдерін қосу/алып тастау:** `types.ts` → `gemini.js` (schema + prompt) → `LessonPreview.tsx` → `docxExport.ts` тізбегінің барлығында сәйкес өріс атын жаңарту қажет.

## Ескертпелер

- **Тема:** ашық/қараңғы таңдау `localStorage`-те сақталады (`qmzh-theme` кілті), тек құрылғыда қалады, серверге жіберілмейді.
- **Қолданушы келісімі / Құпиялылық саясаты** (`client/src/pages/TermsPage.tsx`, `PrivacyPage.tsx`) — жалпы үлгі ретінде дайындалған, заңгерлік кеңес емес. Қызметті коммерциялық негізде толық көлемде іске қосар алдында мәтінді білікті заңгермен қарауды және қажет болса ҚР дербес деректерді қорғау заңнамасына сәйкестендіруді ұсынамыз.
- Gemini модельдерінің атаулары мен тегін квоталары уақыт өте өзгеруі мүмкін — ағымдағы тізімді https://ai.google.dev/gemini-api/docs/models бетінен тексеріп отырыңыз.
